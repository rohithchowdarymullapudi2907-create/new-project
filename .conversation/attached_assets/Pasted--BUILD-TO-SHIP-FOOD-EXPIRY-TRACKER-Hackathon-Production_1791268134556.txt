# 🚀 BUILD-TO-SHIP: FOOD EXPIRY TRACKER
## Hackathon Production-Ready Application — FN8

You are an expert full-stack engineer, UI/UX designer, database architect, and hackathon product builder.

Build a **complete, production-quality web application** called:

# 🥗 FreshTrack — Smart Food Expiry Tracker

The application is being built for a hackathon based on this problem statement:

> **Problem ID: FN8 — Food Expiry Tracker**
>
> Create an application that tracks food products at home and reminds users before expiry.

The goal is to build a polished, intuitive application that solves the problem substantially better than a basic CRUD application.

---

# 1. CORE OBJECTIVE

Build a web application that allows users to:

1. Create an account and securely log in.
2. Add food products stored at home.
3. Track expiry dates.
4. See which foods are:
   - Fresh
   - Expiring soon
   - Expired
5. Receive/see reminders before food expires.
6. Search, filter, sort, and manage food inventory.
7. Edit and delete food items.
8. View useful statistics about household food.
9. Prioritize foods that need attention.
10. Reduce food waste by helping users consume food before it expires.

The final application must feel like a real startup-quality product, not a basic student CRUD project.

# 13. EXPIRY STATUS LOGIC

Rules:

### Expired

expiry_date < today

### Expiring Today

expiry_date = today

### Expiring Soon

expiry date is within the next 3 days

### Fresh

expiry date is more than 3 days away

Make this logic reusable in a utility function.

Example:

getExpiryStatus(expiryDate)

- expired
- today
- soon
- fresh
